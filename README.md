# Revelio 

🔗 **Acesse o projeto:** https://revelio-six.vercel.app/

Revelio é um assistente financeiro pessoal com inteligência artificial desenvolvido para simplificar o controle financeiro de pessoas que nunca utilizaram planilhas ou aplicativos de gestão financeira. O projeto combina análise financeira, processamento de linguagem natural e experiência do usuário para transformar conversas em dados estruturados e insights personalizados.

## O Lio

O coração do Revelio é o **Lio**, um assistente financeiro virtual criado para atuar como um companheiro na organização financeira do usuário.

Diferente de aplicativos tradicionais, o Lio permite que o usuário registre gastos por meio de mensagens simples, como:

> "Mercado 320, Uber 45 e iFood 35"

A partir dessas informações, o assistente interpreta os valores, identifica categorias, registra os gastos automaticamente e atualiza os indicadores financeiros do usuário.

Além disso, o Lio responde dúvidas, fornece orientações personalizadas e adapta suas recomendações de acordo com o perfil financeiro de cada pessoa.

## Objetivo

Muitas pessoas não controlam suas finanças porque os métodos tradicionais exigem planilhas, categorias manuais e conhecimento financeiro básico.

O Revelio foi criado para reduzir essa barreira, oferecendo uma experiência mais natural, intuitiva e acessível através da conversa.

## Principais Funcionalidades

### Assistente Financeiro com IA (Lio)

* Conversação em linguagem natural
* Interpretação automática de gastos
* Recomendações financeiras personalizadas
* Respostas contextualizadas ao perfil do usuário
* Organização automática das informações financeiras

### Dashboard Financeiro

* Receita mensal
* Total gasto
* Saldo disponível
* Barra de progresso do orçamento
* Indicadores visuais de saúde financeira
* Gastos organizados por categoria
* Exclusão de lançamentos incorretos

### Perfil Financeiro Personalizado

* Renda
* Estado civil
* Dependentes
* Filhos

As informações são utilizadas para personalizar análises, recomendações e insights.

## Segurança

O projeto utiliza:

* Autenticação por email e senha
* Confirmação de email
* Row Level Security (RLS)
* Políticas de acesso por usuário
* Banco de dados PostgreSQL hospedado no Supabase

Cada usuário possui acesso apenas às próprias informações financeiras.
